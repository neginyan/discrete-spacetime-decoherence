# Discrete Spacetime Sampling & Matter-Wave Decoherence

Simulation code for verifying objective decoherence and the quantum-to-classical transition via discrete spacetime sampling geometry.

## Manuscript Information
- **Title:** Analytical Derivation of Objective Decoherence and Emergence of Born's Rule via Discrete Spacetime Sampling and Finite-Resolution Gaussian Window Projections
- **Author:** Taishi Namba (Corresponding Author)
- **Journal:** *Quantum Reports* (MDPI)
- **Manuscript ID:** quantumrep-4604349

## Simulation Overview
